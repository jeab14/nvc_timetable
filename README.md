# ระบบจัดตารางสอนอัตโนมัติ วิทยาลัยอาชีวศึกษานครราชสีมา
**NVC Smart Timetable** — Python · Streamlit · PostgreSQL · OR-Tools CP-SAT

ระบบจัดตารางสอนที่เน้น **ความถูกต้องของข้อจำกัดมากกว่าการเติมตารางให้เต็ม**: ตารางที่รายงานว่า “จัดสำเร็จ” ต้องผ่านข้อจำกัดบังคับทุกข้อ และถูกตรวจซ้ำด้วยระบบตรวจสอบอิสระก่อนส่งตรวจ/อนุมัติ/เผยแพร่ทุกครั้ง

## เริ่มใช้งานเร็ว

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py      # ไม่ตั้ง DATABASE_URL = ใช้ SQLite ในเครื่อง (สำหรับทดลอง)
```

ใช้งานจริง/Streamlit Cloud: ตั้ง `DATABASE_URL` เป็น PostgreSQL — ดู **docs/คู่มือติดตั้งและเผยแพร่ระบบ.md**
